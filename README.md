# QA Load Testing Stack: MockServer + Locust + Prometheus + Grafana

> Fully containerized load testing stack for mock API with real-time monitoring.

## Overview

This project demonstrates a professional load testing setup:

- **MockServer** — mock API with 3 endpoints, stateful scenario, and 1s delay
- **Locust** — load generator with 30/20/10 RPS profile and token correlation
- **Prometheus** — metrics collection
- **Grafana** — visualization dashboards
- **Node Exporter** & **cAdvisor** — host and container metrics
